# Google 側の設定手順

回答（文字）を Google スプレッドシートに、録音（WAV）を Google ドライブに保存するための設定です。
最初に1回だけ行います。所要時間は20分ほどです。

- パソコンで作業してください（スマートフォンでは操作しにくい画面があります）。
- 画面の文言は、Google 側の更新で少し変わることがあります。違っていたら、近い意味のものを選んでください。

## 用意するもの

- 保存先にする Google アカウント（回答と録音は、このアカウントのドライブに入ります）
- 貼り付けるプログラム（`gas/Code.gs` の中身。調査項目入りのものを別に受け取っている場合は、そちらを使います）

## 0. 作業用のブラウザの窓を用意する

Google アカウントを2つ以上、同時にログインしていると、途中の画面が開けなかったり、エラーになったりすることがあります。
そこで、**保存先にするアカウントだけ**でログインした窓で作業します。

1. Chrome の右上の「︙」→「新しいシークレット ウィンドウ」を押します（Edge は「新しい InPrivate ウィンドウ」、Safari は「新規プライベートウインドウ」）。
2. その窓で <https://accounts.google.com> を開き、保存先にする Google アカウントでログインします。
3. このあとの手順1〜5は、すべてこの窓の中で行います。

シークレット ウィンドウでうまく進まないときは、Chrome の右上の人の絵 →「追加」で作業用のプロフィールを作り、そこに保存先のアカウントだけでログインして作業してもかまいません。

## 1. スプレッドシートを作る

1. <https://sheets.new> を開きます。空のスプレッドシートができます。
2. 左上の「無題のスプレッドシート」を押して、名前を付けます（例：`方言調査データ`）。

## 2. プログラムを貼り付ける

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を押します。新しいタブで、プログラムを書く画面が開きます。
2. 最初から入っている `function myFunction() { ... }` を、すべて消します（画面の中を1回押してから、Ctrl+A → Delete。Mac は ⌘+A → Delete）。
3. 貼り付けるプログラムの中身をすべてコピーして、貼り付けます（Ctrl+V。Mac は ⌘+V）。
4. 上の「保存」（フロッピーディスクの絵）を押します（Ctrl+S でも保存できます）。

## 3. 初期設定を実行する

1. 画面の上のほうにある、関数名を選ぶ欄（「実行」「デバッグ」の右）で `setup` を選びます。
2. 「実行」を押します。
3. 初回だけ、許可を求める画面が順に出ます。
   1. 「承認が必要です」→「権限を確認」を押す。
   2. 保存先にする Google アカウントを選ぶ。
   3. 「このアプリは Google で確認されていません」と出たら、左下の「詳細」→ いちばん下の「（プロジェクト名）（安全ではないページ）に移動」を押す。
   4. 許可する内容の一覧が出ます。チェック欄がある場合は、すべてにチェックを入れます（「すべて選択」）。
   5. 「許可」または「続行」を押す。
4. 画面の下の「実行ログ」に「初期設定が終わりました。」と出れば成功です。
5. スプレッドシートのタブに戻ると、「設定」「参加者」「歩」「項目」「回答」のシートができています。同じ場所に、録音を入れるフォルダ「方言調査の録音（…）」もできています。

> 手順3の警告は、自分で用意したプログラムを初めて動かすときに必ず出るものです。
> このプログラムが使うのは、このスプレッドシートと、録音を入れるドライブのフォルダです。
> 許可の一覧には「ドライブのすべてのファイル」のように広い書き方で出ますが、これは Google の仕組み上、フォルダを作ったりファイルを保存したりするプログラムには、この書き方の許可しか用意されていないためです。

## 4. 参加者を登録する

1. スプレッドシートのタブを再読み込みします。メニューの右のほうに「方言調査」が増えます。
2. 「方言調査」→「参加者を追加（ナンバーとパスワードを自動で作る）」を押し、人数を入れます。
3. 「参加者」シートに、参加者ナンバー（`K001`、`K002` …）と6けたのパスワードが入ります。これを、登録のときに参加者へ渡します。

自分で決めたナンバーやパスワードを、「参加者」シートに直接書いてもかまいません。
氏名などは書かず、ナンバーと本人の対応表は別に保管することをおすすめします。
動作確認用に、自分用のナンバーを1つ多めに作っておくと便利です。

## 5. ウェブアプリとして公開する

1. Apps Script の画面の右上にある「デプロイ」→「新しいデプロイ」を押します。
2. 「種類の選択」の右にある歯車を押して、「ウェブアプリ」を選びます。
3. 次のように設定します。
   - 説明：何でもかまいません（例：`試行調査`）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押します。
5. 「ウェブアプリ」の URL（`https://script.google.com/macros/s/……/exec`）が表示されます。「コピー」を押して控えます。
6. 新しいタブでその URL を開きます。`"message":"方言調査の保存プログラムは動いています。"` を含む短い文字が表示されれば成功です。
7. **Google にログインしていない窓**でも、同じ URL を開いてみます（作業用とは別に、もう1つシークレット ウィンドウを開くか、スマートフォンで開きます）。同じ文字が表示されれば、参加者も使えます。Google のログイン画面が出る場合は、下の「うまくいかないとき」を見てください。

「アクセスできるユーザー」を「全員」にするのは、参加者が Google アカウントなしで使えるようにするためです。
だれでも URL に接続はできますが、参加者ナンバーとパスワードが合わないかぎり、項目の受け取りも回答の保存もできません。

## 6. サイトに URL を入れる

サイトの `config.js` の次の行の `""` の中に、手順5で控えた URL を入れます。

```js
apiUrl: "",
```

↓

```js
apiUrl: "https://script.google.com/macros/s/……/exec",
```

GitHub の画面で直すときは、次の順に押します。

1. リポジトリの `config.js` を開く。
2. 右上の鉛筆の絵（Edit this file）を押す。
3. `apiUrl: "",` の `""` の中に URL を貼り付ける。
4. 右上の「Commit changes…」を押す。
5. 出てきた窓の「Commit changes」を押す。

数分たつと、公開中のサイトに反映されます。
URL の形が正しくないときは、サイトの最初のページに赤い枠で「設定の確認」と表示されます。

## 7. 動作を確かめる

自動のテストは、Google の「まね」をするプログラムを相手に行っています。**Google の実物と、実物のスマートフォンでの確認は、ここで初めて行います。** 参加者に渡す前に、必ず行ってください。

1. スマートフォンでサイトを開き、自分用の参加者ナンバーとパスワードでログインします。
2. 録音のれんしゅうをします。「声は録音できています」と出ることを確かめます。
3. 1歩目の問題に答えます。回答の欄には、ためしに `001` と書いてみてください（数字が正しく残るかを見るためです。「ひらがなで書いてください」と出ますが、そのまま進めます）。
4. 画面の右上が「送信ずみ」になることを確かめます。
5. パソコンで、スプレッドシートの「回答」シートを開きます。1問につき1行増えていて、回答が `001`（`1` ではなく）と入っていれば、文字の保存は正常です。
6. 同じ行の「録音1リンク」を押して、録音が再生できることを確かめます。
7. 同じ行の「声と雑音の差（dB）」に数字が入っていることを確かめます（静かな部屋で録ると、大きな数字になります）。テレビなどを鳴らした部屋でも1問録ってみて、数字が小さくなることと、画面に「まわりの音が大きいようです」と出るかどうかを見ておくと、注意の出方の目安になります。
8. iPhone と Android の両方の参加者がいる場合は、それぞれの機種で手順1〜7を行います。

確認が終わったら、テストの回答は消してかまいません。

- 「回答」シートのテストの行は、行ごと削除します（見出しの1行目は消さないでください）。
- 録音フォルダの中のテストのファイル（またはテスト用ナンバーのフォルダ）は、ごみ箱に入れます。
- 自分用のナンバーで歩を進めた記録は、「回答」シートの行を消せば、次にログインしたときに元にもどります。

## 8. 管理画面を開いてみる

進み具合や、届いた回答・録音を確かめるための画面です（くわしくは [operation.md](operation.md) の「管理画面」）。

1. 作業用の窓（保存先のアカウントでログインしている窓）で、手順5で控えた URL の最後に `?admin=1` を付けて開きます（例：`https://script.google.com/macros/s/……/exec?admin=1`）。
2. 「ダッシュボード」が出れば成功です。このページを、ブックマークに入れておきます。
3. スプレッドシートのメニュー「方言調査」→「管理画面を開く」でも、同じ画面が開きます。

## プログラムを新しくしたとき

プログラムを貼りかえて保存しただけでは、公開中のものは変わりません。次の操作を、**この順番で**行います。
（下の5で「デプロイ」を押すまでは、参加者の画面は、前のプログラムのままで動きつづけます。）

1. Apps Script の画面で、プログラムをすべて貼りかえて保存します（手順2と同じやり方です）。
2. 関数名を選ぶ欄で `setup` を選び、「実行」を押します。
   - 新しいプログラムで使う機能が増えたときは、**もう一度、許可を求める画面が出ます**。「3. 初期設定を実行する」の3と同じように進めてください。許可する内容の一覧にチェック欄がある場合は、**すべてにチェックを入れて**（「すべて選択」）から「続行」を押します。
   - 画面の下の「実行ログ」に「初期設定が終わりました。」と出れば成功です。新しいプログラムで増えた列や設定の項目のうち、足りないものだけが足されます（今あるデータは変わりません）。
3. 右上の「デプロイ」→「デプロイを管理」を押します。
4. 右上の鉛筆の絵（編集）を押します。
5. 「バージョン」を「新バージョン」に変えて、「デプロイ」を押します。
6. ウェブアプリの URL を開いて、表示される文字の中の `"version"` が新しい番号になっていることを確かめます。
7. スプレッドシートのタブを再読み込みします（メニュー「方言調査」が新しくなります）。

この方法なら、URL は変わりません（「新しいデプロイ」を選ぶと URL が変わってしまうので、使いません）。

上の2を飛ばしてデプロイすると、許可が足りないために、参加者の画面から保存先につながらなくなることがあります。その場合は、2を行えば直ります（そのあいだの回答は参加者の端末に残っていて、あとで自動的に送られます）。

## うまくいかないとき

| こうなったら | 確かめること |
| --- | --- |
| Apps Script の画面が開かない／「リダイレクトが繰り返し行われました」「問題が発生しました」などと出る | Google アカウントを2つ以上ログインしているときに起こります。手順0のとおり、シークレット ウィンドウで、保存先のアカウントだけでログインしてやり直してください。 |
| 手順3で「アクセスが拒否されました: DriveApp」などと出る | 大学や組織の Google アカウントで、ドライブをプログラムから使うことが止められています。個人の Google アカウントで手順0からやり直してください。 |
| 手順5で「全員」が選べない | 大学や組織の Google アカウントでは、組織の外への公開が止められていることがあります。個人の Google アカウントで手順0からやり直してください。 |
| 手順5-6・5-7で Google のログイン画面が出る | 「アクセスできるユーザー」が「全員」になっていません。「デプロイを管理」→ 鉛筆 → 設定を直して「デプロイ」。組織のアカウントで直らない場合は、個人の Google アカウントで手順0からやり直してください。 |
| URL が `https://script.google.com/a/macros/（組織名）/s/……/exec` の形になっている | 組織の Google アカウントで作ると、この形になることがあります。そのまま `config.js` に入れてかまいません（サイトの側で、ログインなしで使える形に読みかえます）。そのうえで、手順5-7の確認を必ず行ってください。 |
| 手順5-6で「初期設定がまだ…」と出る／`"ready":false` と出る | 手順3（`setup` の実行）が終わっていません。 |
| サイトでログインできない | 「参加者」シートのナンバーとパスワード、「状態」が「停止」になっていないか、「設定」シートの「受付」が「停止中」になっていないかを確かめてください。8回続けてまちがえると、15分間ログインできなくなります。 |
| サイトの右上が「お試しモード」のまま | `config.js` の `apiUrl` が空か、URL の形がちがいます（`https://script.google.com/macros/s/` で始まり `/exec` で終わる形）。形がちがうときは、最初のページに「設定の確認」と出ます。書きかえた直後は、反映まで数分かかります。 |
| サイトで「通信できませんでした」と出る | 手順5-7の確認をもう一度行ってください。ログインしていない窓で URL を開いて文字が出ない場合は、デプロイの設定を直します。 |
| 管理画面（`?admin=1`）を開くと、「この画面は開けませんでした」という文字が出る | スプレッドシートの持ち主の Google アカウントでログインしていないか、ほかのアカウントにも同時にログインしています。手順0のように、持ち主のアカウントだけでログインした窓で開いてください。それでも開けないときは、スプレッドシートのメニュー「方言調査」→「管理画面を開く」から開きます。 |
| 管理画面が「読みこめませんでした」のまま進まない／ボタンを押しても動かない | Google アカウントを2つ以上ログインしているときに起こります。ほかのアカウントからログアウトするか、シークレット ウィンドウで、持ち主のアカウントだけでログインして開いてください。 |
| メニュー「方言調査」に「管理画面を開く」がない | プログラムが古いか、スプレッドシートのタブを再読み込みしていません。「プログラムを新しくしたとき」の手順を、さいごまで行ってください。 |
| 管理画面で「開き直してください」と出る | 開いてから12時間たつと、安全のために使えなくなります。ページを読みこみ直すと、また使えます。 |
| プログラムを新しくしたあと、参加者の画面で「通信できませんでした」と出る | 「プログラムを新しくしたとき」の2（`setup` の実行と、許可）を行っていないことがあります。2を行い、許可の画面では、すべてのチェック欄にチェックを入れてください。 |
| ログインはできるが、回答が保存されない（右上が「未送信」のまま） | 「回答」シートの名前や、1行目の見出しを書きかえていないか確かめてください。録音フォルダをごみ箱に入れていないかも確かめてください。直すと、たまっていた回答は自動で送られます。 |
