# ほかの地域・ほかの調査でも使う

このサイトは、鹿児島以外の方言調査にも、そのまま使えます。考え方は「サイトは1つ、保存先（Google のスプレッドシート）は調査ごと」です。

- 参加者の画面（このサイト）は、だれが使っても同じものです。サイトのファイルをコピーしたり、GitHub を使ったりする必要はありません。
- 回答と録音は、調査ごとに、その調査の担当者の Google アカウントのスプレッドシートとドライブに入ります。ほかの調査の担当者には見えません。
- 題名・紹介文・案内役（キャラクター）・景色・設問は、スプレッドシートの「設定」「項目」シート（管理画面）で決めます。鹿児島らしさのない見た目にもできます。

## 用意するもの

- Google アカウント（スプレッドシートとドライブを使います。回答と録音は、このアカウントの中に保存されます）
- 貼り付けるプログラム（このリポジトリの `gas/Code.gs`。見本の設問が5問入っています）
- 設問の表（Excel。列の見出しは `docs/operation.md` の「項目」を見てください）

## 手順

1. [setup-google.md](setup-google.md) の **1〜5** を、そのまま行います（スプレッドシートを作る → プログラムを貼り付ける → `setup` を実行する → 参加者を登録する → ウェブアプリとして公開する）。
   公開でできた URL `https://script.google.com/macros/s/（ID）/exec` の **（ID）の部分**（`AKfycb` で始まる長い文字）を控えます。
2. 参加者に案内するアドレスは、次の形です。（ID）のところに、控えた文字を入れます。
   `https://mikasakai0923.github.io/kagoshimacity-dialect/?s=（ID）`
   このアドレスで開くと、サイトはあなたの保存先につながります。`?s=` がないアドレスで開くと、鹿児島の調査につながるので、必ず `?s=` つきのアドレスを案内してください（参加者カードの QR コードは、下の設定をすれば `?s=` つきになります）。
3. スプレッドシートのメニュー「方言調査」→「管理画面を開く」で、管理画面を開きます。
4. 「設定」で、次を決めて保存します。
   - 「サイトのURL」に、2 のアドレス（`?s=` つき）を入れる。管理画面の「参加者の画面を開く」と、参加者カードの印刷に使われます。
   - 「参加者の画面の見た目」で、案内役と景色をえらぶ（鹿児島以外なら、景色は「ノーマル」、案内役は桜島大根以外がおすすめです）。案内役の名前も決められます。
   - 「紹介ページの文章」に、サイトの名前・紹介のことば・紹介文・回答と声のあつかい・実施者・問い合わせ先を書く。
   - 「参加者ナンバーの頭文字」を、調査ごとに別のものにする（例：`A`、`OK`）。
5. 「項目」→「表から取りこむ」で、設問の Excel を取りこみます（下見で確かめてから「取りこむ」）。
6. 2 のアドレスをスマートフォンで開き、自分用の参加者ナンバーでログインして、録音のれんしゅうと最初の1問を試します。回答が「回答」シートに入り、録音がドライブの「方言調査の録音（…）」に入れば完成です。

## 知っておくこと

- サイトのプログラムが新しくなると、すべての調査の参加者の画面が同時に新しくなります（保存先のプログラムは、調査ごとに貼りかえます。`docs/setup-google.md` の「プログラムを新しくしたとき」）。
- 1台のスマートフォンで2つの調査を使っても、まざりません。調査ごとに別々にログインし、進み具合も別々に覚えます。まだ送られていない回答は、その調査のアドレスを開いたときだけ、その調査の保存先に送られます。
- 「お試しモード」（`?demo=1`）は、保存先を使わずに画面だけを試せます。見た目は `?demo=1&mascot=まる&scenery=ノーマル` のようにつけて試せます。
