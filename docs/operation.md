# 運用の手引き

調査の内容や参加者は、すべて Google スプレッドシートを書きかえるだけで管理できます。
書きかえた内容は、参加者が次に地図の画面を開いたときに反映されます（直前に読みこんだばかりの場合は、数分後に開いたときから）。

## シートの役割

| シート | 役割 | 書きかえ |
| --- | --- | --- |
| 設定 | 受付の開始・停止、教示文、質問文など | できます |
| 参加者 | 参加者ナンバーとパスワード | できます |
| 歩 | すごろくの歩の名前とマスの絵 | できます |
| 項目 | 調査項目 | できます |
| 回答 | 届いた回答（1回答1行） | 書きかえないでください（並べかえ・絞りこみは可） |
| 進み具合 | 参加者ごとの回答数（メニューから作る） | 作り直すたびに上書きされます |

## 参加者

| 列 | 内容 |
| --- | --- |
| 参加者ナンバー | ログインに使う番号。英数字。大文字・小文字、全角・半角は区別しません。 |
| パスワード | ログインに使うパスワード。全角・半角は区別しません（大文字・小文字は区別します）。 |
| 状態 | `停止` と書くと、その参加者はログインも送信もできなくなります。空欄か `有効` なら使えます。 |
| メモ | 自由に使えます（氏名などの個人情報は書かないことをおすすめします）。 |
| 登録日・最終ログイン | 自動で入ります。 |

- メニュー「方言調査」→「参加者を追加」で、ナンバーと6けたのパスワードをまとめて作れます。
- パスワードは、このシートを見られる人には読める形で保存されます。シートの共有相手は必要最小限にしてください。
- パスワードを自分で決める場合は、6文字以上をおすすめします。
- ログインは30日間有効です。家族で1台を使う場合は、メニューの「ログアウト」で切りかえます。

## 項目

1行が1問です。

| 列 | 内容 |
| --- | --- |
| 歩 | 何歩目に出すか（1, 2, 3 …）。 |
| 順 | その歩の中での順番。 |
| 設問ID | 回答と結びつける番号。**同じIDを2回使わないでください。** 途中で変えると、変える前の回答と結びつかなくなります。 |
| 種別 | `語彙` か `例文`。 |
| 提示語・例文 | 参加者に見せることば・文。 |
| 場面・意味・読み | 質問の下に出る説明。`読み：` で始めると読みがなとして、それ以外は「場面」として出ます。 |
| 提案例文（語彙） | 語彙の項目で、例文も答えてもらう場合に書きます。書くと、回答欄と録音が1組ふえます。 |
| 文節の区切り | 例文を文節に分けたもの。`｜` で区切ります（例：`私は｜明日｜町へ｜行く`）。半角の `|` や `/` でも区切れます。 |
| イラスト | 下の「イラスト」を見てください。空欄なら絵は出ません。 |
| 出す | `FALSE` にすると、その項目は出なくなります（行を消さずに一時的に外したいとき）。 |
| 記述項目・調査の狙い | 調査者用のメモ。参加者には見えません。 |

### ふりがな

漢字のすぐあとに `《よみ》` を書くと、ふりがなになります（例：`鯖《さば》を焼いた`）。
「提示語・例文」「場面・意味・読み」「提案例文」「文節の区切り」で使えます。回答シートには、ふりがなを除いた形で記録されます。

### イラスト

「イラスト」欄には、次のどれかを書きます。

- サイトに入っている絵の名前（半角英数字）。空白で区切ると横に並びます。
  - 例：`tree`、`boy rock dash`
  - `>` を入れると矢印、`/` を入れると少し間をあけて2組に分けます（例：`me > town`、`me girl > / person house`）。
  - `名前*1.3` のように書くと大きさを変えられます（0.4〜1.6）。
- 自分で用意した画像のファイル名（例：`atama.png`）。画像は、サイトの `images` フォルダに入れておきます。
- 画像のアドレス（`https://` で始まるもの）を1つ。

サイトに入っている絵の一覧は `images/icons/` を見てください（ファイル名から `.svg` を除いたものが名前です）。

## 歩

| 列 | 内容 |
| --- | --- |
| 歩 | 歩の番号。 |
| タイトル | 地図に出る名前（例：`天文館`）。空欄でもかまいません。 |
| アイコン | マスに出す絵の名前（`images/icons/` の絵）。空欄なら数字が出ます。 |

「項目」シートに1問もない歩は、地図に出ません。

## 設定

| 項目 | 内容 |
| --- | --- |
| 受付 | `停止中` にすると、だれもログイン・送信できなくなります。 |
| お知らせ | 書くと、参加者の地図の画面の上に出ます。 |
| 教示文 | すべての設問の上に出る説明。 |
| 語彙の質問文 | `{語}` のところに提示語が入ります。 |
| 例文の質問文 | `{文}` のところに例文が入ります。 |
| 録音の上限（秒） | 1回の録音の上限（5〜60）。 |
| 参加者ナンバーの頭文字 | 自動で作るナンバーの頭文字。 |
| 録音フォルダ | 録音の保存先（自動で入ります。書きかえないでください）。 |

## 回答

1回の回答が1行になります。同じ設問にもう一度答えた場合は、行が増えます（前の回答も残ります）。

| 列 | 内容 |
| --- | --- |
| 送信日時 | 保存先に届いた日時（日本時間）。 |
| 参加者ナンバー／歩／設問ID／種別／提示語・例文 | 回答したときに参加者が見ていた内容。 |
| 回答の状態 | `回答済`／`知らない`／`使わない`／`思い出せない`。 |
| 回答（地域の言葉） | 語彙はその語。例文は、文節ごとの回答を空白でつないだもの。 |
| 文節（提示）／文節（回答） | 例文の文節と、それぞれに対する回答（`｜` 区切り。書かなかった文節は空）。 |
| 提案例文の回答 | 語彙の項目の例文への回答。 |
| 別形・意味・補足 | 「他の言い方」などの欄に書かれた内容。 |
| 録音1／録音1リンク | 回答の録音のファイル名と、ドライブで開くリンク。 |
| 録音2／録音2リンク | 提案例文の録音（ある場合）。 |
| 録音なしの理由 | 参加者が「マイクが使えない」を選んで回答した場合に入ります。 |
| 録音の長さ（秒）／サンプリング周波数 | 録音1のもの。 |
| 回答にかかった秒数 | 設問が表示されてから「つぎへ」を押すまで。 |
| 端末 | おおまかな機種とブラウザ。 |
| 端末での回答日時 | 参加者の端末の時計での日時（通信できなかった回答は、送信日時より前になります）。 |
| 送信ID | 二重登録を防ぐための番号。 |
| 技術情報 | 録音の最大音量や、端末の自動補正（雑音除去など）が切れていたかどうか。 |

### 録音

- 形式：WAV（無圧縮・16ビット・モノラル）。サンプリング周波数は端末まかせ（多くは 44,100 Hz か 48,000 Hz）。
- 端末の自動補正（エコー除去・雑音除去・音量の自動調整）は、切るように求めています。端末によっては切れないことがあり、その結果は「技術情報」に残ります（`ec`・`ns`・`agc` が `true` なら、切れていません）。
- 保存場所：録音フォルダ → 参加者ナンバーのフォルダ。
- ファイル名：`参加者ナンバー_設問ID_kaitou_日付-時刻_送信IDの先頭.wav`（提案例文は `kaitou` のかわりに `reibun`）。

### 進み具合

メニュー「方言調査」→「進み具合を更新」で、参加者ごとの回答数をまとめた「進み具合」シートを作ります。

## 参加者の画面について

- 回答は、まず参加者の端末の中に保存され、通信できるときに自動で送られます。画面の右上が「送信ずみ」になっていれば、すべて届いています。
- 通信できないまま端末のブラウザのデータを消すと、まだ送られていない回答は失われます。
- 録音は原則として必須です。参加者が「マイクが使えないとき」→「録音なしで進む」を選んだ場合だけ、文字の回答だけで進めます。

## 知っておくとよい上限

- 1回の保存には数秒かかり、同時に処理できる数にも Google 側の上限があります。試行調査の規模では問題になりませんが、保存先がこみあった場合、回答は参加者の端末に残り、あとで自動的に送り直されます。
- 回答が数万行を超えると、ログイン直後の読みこみが遅くなります。数百人規模で使う前に、作りを見直してください。
