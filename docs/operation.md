# 運用の手引き

ふだんの確認（進み具合、届いた回答と録音）と、よく使う操作（参加者の追加、受付の開始・停止、設問の書きかえや取りこみなど）は、**管理画面**で行えます。
細かい作業は、Google スプレッドシートを直接書きかえて行うこともできます。
書きかえた内容は、参加者が次に地図の画面を開いたときに反映されます（直前に読みこんだばかりの場合は、数分後に開いたときから）。

## 管理画面

調査者のための画面です。パソコンでも、スマートフォンでも使えます。

### 開き方

次のどちらかで開きます。

- **ウェブアプリの URL の最後に `?admin=1` を付けて開く**（例：`https://script.google.com/macros/s/……/exec?admin=1`）。ブックマークに入れておくと便利です。
  - スプレッドシートの持ち主の Google アカウントでログインしているブラウザでだけ開けます。ほかの人が開いても、「この画面は開けませんでした」という文字が出るだけです。
- **スプレッドシートのメニュー「方言調査」→「管理画面を開く」**を押す。スプレッドシートの上に、窓の形で開きます。

開けないときは、[setup-google.md](setup-google.md) の「うまくいかないとき」を見てください。

### 5つの画面

| 画面 | できること |
| --- | --- |
| ダッシュボード | 受付の状態、参加者の人数、集まった回答の数、ゴールした人数。日ごと（週ごと）の回答数のグラフ。歩ごとに、歩きおえた人数。直近の回答と、参加者ごとの進み具合。「雑音の多い録音」「録音なしの回答」があれば、その件数（押すと、その回答の一覧が出ます）。 |
| 参加者 | 参加者の一覧と進み具合。参加者の追加（ナンバーとパスワードを自動で作る）。パスワードの表示。参加者カード（ナンバー・パスワード・サイトのアドレスとQRコード）の印刷。メモ。参加者ごとの停止・再開。 |
| 回答と録音 | 届いた回答を新しい順に表示。参加者・歩・回答の状態・録音の注意・文字でのしぼりこみ。録音をその場で再生。「くわしく」を押すと、文節ごとの回答や端末の情報。録音（WAV）の保存。 |
| 項目 | 設問ごとに、何人が答えたかと、「回答済／知らない／使わない／思い出せない」の内訳。設問を1つずつ直す・足す、「出さない」にする、歩の名前を直す。Excel や CSV の表（抜粋ツールが作ったものなど）から、設問をまとめて取りこむ。 |
| 設定 | 受付の開始・停止。お知らせ・教示文・質問文。録音の上限。雑音の注意の目安。参加者ナンバーの頭文字。サイトのURL。 |

### 知っておくとよいこと

- 画面の内容は、1分ごとに自動で新しくなります。すぐに新しくしたいときは、右上の「更新」を押します。
- 「回答と録音」の一覧は、見ているとちゅうで勝手に入れかわりません。新しい回答が届くと、一覧の上に知らせが出ます。
- 録音の再生では、音量の小さい録音（iPhone など）を、聞きとりやすい大きさにして流します（「音を大きくして再生」のチェックで切りかえられます）。保存されている録音は変わりません。
- 管理画面は、開いてから12時間たつと、安全のために使えなくなります。「開き直してください」と出たら、ページを読みこみ直してください（メニューから開いた窓は、いったん閉じて開き直します）。
- 参加者カードは、画面の「印刷する」ボタンで印刷します（A4 の紙1枚に6枚）。ブラウザのメニューから印刷すると、うまく印刷できないことがあります。印刷は、パソコンから行うのが確実です。
- 「設定」の「サイトのURL」に、参加者に案内するサイトのアドレスを入れておくと、参加者カードにアドレスとQRコードが印刷されます。
- 設問の追加や書きかえは、管理画面の「項目」でできます（下の「項目」の節を見てください）。スプレッドシートの「項目」シートを直接書きかえてもかまいません。
- 「パスワードを表示」や参加者カードには、パスワードがそのまま出ます。まわりの人に画面を見られないようにしてください。
- スプレッドシートを共有している相手（編集者）も、メニューから管理画面を開けます。スプレッドシートの共有相手は、必要最小限にしてください。
- メモは500文字までです。それより長いメモは、「参加者」シートに直接書いてください。
- 設問の各欄にも長さの上限があります（提示語・例文 300 文字、場面・意味・読み 600 文字、文節の区切り 400 文字など）。1回に取りこめる設問は 2000 件までです。

## シートの役割

| シート | 役割 | 書きかえ |
| --- | --- | --- |
| 設定 | 受付の開始・停止、教示文、質問文など | できます |
| 参加者 | 参加者ナンバーとパスワード | できます |
| 歩 | すごろくの歩の名前とマスの絵 | できます |
| 項目 | 調査項目 | できます |
| 回答 | 届いた回答（1回答1行） | 中身は書きかえないでください（下の注意を見てください） |
| 進み具合 | 参加者ごとの回答数（メニューから作る） | 作り直すたびに上書きされます |

**シートの名前と、各シートの1行目の見出しは、変えないでください。** プログラムは、名前と見出しをたよりに読み書きしています。
「回答」シートは、並べかえ・絞りこみ・列の追加・テストの行の削除をしてもかまいません。
「参加者」シートも、列を足したり、列の順番を入れかえたりしてかまいません（見出しの名前は、そのままにしてください）。

## 登録のとき（対面）に確かめること

参加者のスマートフォンで、次のことをいっしょに行っておくと、あとの問い合わせが減ります。

1. サイトを、iPhone は Safari、Android は Chrome で開きます。LINE やメールのアプリの中で開いた画面では、録音できないことがあります。
2. 開いたページを、ブックマークかホーム画面に追加しておきます（次に開きやすくするため）。
3. 参加者ナンバーとパスワードでログインします。
4. イヤホンやヘッドセットをつけている場合は、はずしてもらいます（無線のイヤホンのマイクで録音されると、音がこもります）。
5. 「録音のれんしゅう」を行います。マイクの使用をたずねられたら「許可」を選び、「声は録音できています」と出ることを確かめます。「まわりの音が大きいようです」と出たら、テレビや換気扇などを止めるか、静かな場所に移って、ためし直します。
6. iPhone の場合は、下の「iPhone でマイクの許可を毎回たずねられないようにする」を設定します。
7. 1問目をいっしょに答えて、右上が「送信ずみ」になることを確かめます。

### iPhone でマイクの許可を毎回たずねられないようにする

iPhone の Safari は、何も設定しないと、録音のたびに「マイクの使用を許可しますか」とたずねることがあります（前の録音からしばらくたつと、もう一度たずねる仕組みのため）。
1問ごとにたずねられると負担が大きく、まちがって「許可しない」を押すと録音できなくなるので、登録のときに、次のどちらかを設定しておくことを強くおすすめします。

- サイトごとに設定する：サイトを開いた状態で、アドレス欄の左はしのボタン（iOS 17 までは「ぁあ」。iOS 18 以降は、形のちがうページメニューのボタン）を押す →「Webサイトの設定」（見当たらないときは「…」の中）→「マイク」→「許可」。
- Safari 全体で設定する：「設定」アプリ →「アプリ」→「Safari」（iOS 17 までは「設定」→「Safari」）→「マイク」→「許可」。

iOS のバージョンによって、ボタンの場所や名前が少し違います。実物の iPhone で一度ためしてから、参加者に案内してください。

Android の Chrome では、最初にたずねられたときに、「今回のみ」ではないほうの許可を選ぶと、次からはたずねられません。

## 参加者

| 列 | 内容 |
| --- | --- |
| 参加者ナンバー | ログインに使う番号。英数字。大文字・小文字、全角・半角は区別しません。 |
| パスワード | ログインに使うパスワード。全角・半角は区別しません（大文字・小文字は区別します）。 |
| 状態 | `停止` と書くと、その参加者はログインも送信もできなくなります。空欄か `有効` なら使えます。 |
| メモ | 自由に使えます（氏名などの個人情報は書かないことをおすすめします）。 |
| 登録日・最終ログイン | 自動で入ります。 |

- 管理画面の「参加者」→「参加者を追加」か、メニュー「方言調査」→「参加者を追加」で、ナンバーと6けたのパスワードをまとめて作れます。
- 「状態」と「メモ」は、管理画面の「参加者」でも書きかえられます（「停止する」「再開する」のボタンと、えんぴつの絵）。
- 年代や地域などを書いておきたいときは、列を足してかまいません。プログラムは、自分の見出しの列（参加者ナンバー・パスワード・状態・メモ・登録日・最終ログイン）だけを読み書きします。
- パスワードは、このシートを見られる人には読める形で保存されます。シートの共有相手は必要最小限にしてください。
- パスワードを自分で決める場合は、6文字以上をおすすめします。
- ログインは30日間有効です。家族で1台を使う場合は、メニューの「ログアウト」で切りかえます。

## 項目

1行が1問です。管理画面の「項目」で直すときも、下の列と同じ欄が出ます。

| 列 | 内容 |
| --- | --- |
| 歩 | 何歩目に出すか（1, 2, 3 …）。 |
| 順 | その歩の中での順番。 |
| 設問ID | 回答と結びつける番号。**同じIDを2回使わないでください。** 途中で変えると、変える前の回答と結びつかなくなります。 |
| 種別 | `語彙` か `例文`。 |
| 提示語・例文 | 参加者に見せることば・文。 |
| 場面・意味・読み | 質問の下に出る説明。`読み：` で始めると読みがなとして、それ以外は「場面」として出ます。 |
| 提案例文（語彙） | 語彙の項目で、例文も答えてもらう場合に書きます。書くと、回答欄と録音が1組ふえます。 |
| 文節の区切り | 例文を文節に分けたもの。`｜` で区切ります（例：`私は｜明日｜町へ｜行く`）。半角の `|` や `/` でも区切れます。 |
| イラスト | 下の「イラスト」を見てください。空欄なら絵は出ません。 |
| 出す | `FALSE` にすると、その項目は出なくなります（行を消さずに一時的に外したいとき）。 |
| 記述項目・調査の狙い | 調査者用のメモ。参加者には見えません。 |

### 管理画面で直す・足す・取りこむ

管理画面の「項目」でできることです。

- **直す**：設問の右の「直す」を押すと、その設問の欄がそろった窓が開きます。直して「保存する」を押すと、「項目」シートの同じ行が書きかわります。
  - 回答のある設問は、設問IDを変えられません（回答は設問IDで結びついています）。提示語・例文や文節を変えると注意が出ます。前の回答は残りますが、新しい文との対応は調査者が見分ける必要があります。
  - 文節の区切りは、つなげた文字が提示語・例文と合わないと、窓の中で注意が出ます（句読点とふりがなは除いてくらべます）。
- **出さない／出す**：設問を消すかわりに、参加者の画面から外します。回答は残ります。外した設問は、一覧の下の「出していない設問」にまとまって、あとから「出す」にもどせます。「項目」シートでは「出す」の列が `FALSE` になります。
- **設問を足す**：新しい設問を1つ足します。「順」を空欄にすると、その歩の最後に入ります。
- **名前を直す**：歩の見出しの横の「名前を直す」で、すごろくのマスに出る名前とアイコンを直せます。
- **表から取りこむ**：たくさんの設問をまとめて入れるときに使います。
  1. 「ファイルをえらぶ」で Excel（.xlsx）か CSV・タブ区切りのファイルをえらぶか、Excel の表をコピーして貼りつけます。1行目は「項目」シートと同じ見出しにします（歩・順・設問ID・種別・提示語・例文・場面・意味・読み・提案例文（語彙）・文節の区切り・イラスト・出す・記述項目・調査の狙い。歩・設問ID・提示語・例文の3つは必ず要ります）。抜粋ツールが作った Excel なら、そのままえらべます。「歩」という名前のシートがあれば、歩の名前もいっしょに入ります。
  2. 取りこみ方をえらびます。**ぜんぶ入れかえる**は、表にある設問だけにします（表にない設問は消えますが、回答のある設問は消さずに「出さない」にして残します）。**足す・直すだけ**は、表にある設問を足したり直したりするだけで、表にない設問はそのままです。
  3. 「下見する」を押すと、直さないと取りこめないところ（空の設問ID、同じ設問IDが2つ、歩が数字でない、長すぎる文など）と、何が足され・直され・消えるかが出ます。直すところがあるときは、表を直してから、もう一度「下見する」を押します。
  4. 「この内容で取りこむ」で書きこみます。書きこむ前に、いまの「項目」「歩」シートの控え（「項目（控え 2026-10-23 16:40）」のような名前のシート）が自動でとられます。控えは新しい5つまで残り、古いものから消えます。
  - 表にない列（たとえば「場面・意味・読み」の列がない表）は、いまの値のままにします。新しく足す設問では空欄になります。
  - 取りこみで変わるのは「項目」シートの決まった列だけです。自分で足した列や、見出しのない列に書いたことは、同じ設問IDの行にそのまま残ります。数式も残りますが、「ぜんぶ入れかえる」で行の並びが変わると、数式の参照先（`E3` など）はそのままなので、ずれることがあります。文字の色やリンクなどの飾りは、取りこみで消えることがあります。「歩」シートの行は消さず、並べかえもしません。
- **控えからもどす**：取りこんだあとで「やっぱり前の設問にもどしたい」ときは、「項目」の上の知らせにある「控えからもどす」を押し、日時をえらびます。えらんだ控えの内容が「項目」「歩」シートにもどり、参加者の画面もその内容になります。もどす前のいまの内容も控えにとるので、もどしたこと自体をまたもどせます。

### ふりがな

漢字のすぐあとに `《よみ》` を書くと、ふりがなになります（例：`鯖《さば》を焼いた`）。
「提示語・例文」「場面・意味・読み」「提案例文」「文節の区切り」で使えます。回答シートには、ふりがなを除いた形で記録されます。

### イラスト

「イラスト」欄には、次のどれかを書きます。

- サイトに入っている絵の名前（半角英数字）。空白で区切ると横に並びます。
  - 例：`tree`、`boy rock dash`
  - `>` を入れると矢印、`/` を入れると少し間をあけて2組に分けます（例：`me > town`、`me girl > / person house`）。
  - `名前*1.3` のように書くと大きさを変えられます（0.4〜1.6）。
- 自分で用意した画像のファイル名（例：`atama.png`）。画像は、サイトの `images` フォルダに入れておきます。
- 画像のアドレス（`https://` で始まるもの）を1つ。

サイトに入っている絵の一覧は `images/icons/` を見てください（ファイル名から `.svg` を除いたものが名前です）。
絵が読みこめなかったときは、絵の枠ごと表示されません（問題には答えられます）。

画像のアドレスを書いた場合、参加者の端末は、その画像が置いてあるサイトに接続します。参加者の接続の記録を外部に残したくないときは、画像をサイトの `images` フォルダに入れて、ファイル名で指定してください。

## 歩

| 列 | 内容 |
| --- | --- |
| 歩 | 歩の番号。 |
| タイトル | 地図に出る名前（例：`天文館`）。空欄でもかまいません。 |
| アイコン | マスに出す絵の名前（`images/icons/` の絵）。空欄なら数字が出ます。 |

「項目」シートに1問もない歩は、地図に出ません。

## 設定

| 項目 | 内容 |
| --- | --- |
| 受付 | `停止中` にすると、だれもログイン・送信できなくなります。 |
| お知らせ | 書くと、参加者の地図の画面の上に出ます。 |
| 教示文 | すべての設問の上に出る説明。 |
| 語彙の質問文 | `{語}` のところに提示語が入ります。 |
| 例文の質問文 | `{文}` のところに例文が入ります。 |
| 録音の上限（秒） | 1回の録音の上限（5〜60。はじめは20）。長くすると、通信のおそい場所では送信に時間がかかります。 |
| 雑音の注意の目安（dB） | 声と、まわりの音の大きさの差が、この数字より小さい録音に「まわりの音が大きいようです」と注意を出します（5〜40。はじめは20）。数字を大きくすると、きびしくなります。`0` にすると注意を出しません。くわしくは、下の「まわりの音（雑音）」を見てください。 |
| 参加者ナンバーの頭文字 | 自動で作るナンバーの頭文字。 |
| サイトのURL | 参加者に案内するサイトのアドレス。管理画面の「参加者の画面を開く」と、参加者カードの印刷に使います。 |
| 録音フォルダ | 録音の保存先（自動で入ります。書きかえないでください）。 |

「録音フォルダ」のほかは、管理画面の「設定」でも変えられます。

## 回答

1回の回答が1行になります。同じ設問にもう一度答えた場合は、行が増えます（前の回答も残ります）。

| 列 | 内容 |
| --- | --- |
| 送信日時 | 保存先に届いた日時（日本時間）。 |
| 参加者ナンバー／歩／設問ID／種別／提示語・例文 | 回答したときに参加者が見ていた内容。 |
| 回答の状態 | `回答済`／`知らない`／`使わない`／`思い出せない`。 |
| 回答（地域の言葉） | 語彙はその語。例文は、文節ごとの回答を空白でつないだもの。 |
| 文節（提示）／文節（回答） | 例文の文節と、それぞれに対する回答（`｜` 区切り。書かなかった文節は空）。 |
| 提案例文の回答 | 語彙の項目の例文への回答。 |
| 別形・意味・補足 | 「他の言い方」などの欄に書かれた内容。 |
| 録音1／録音1リンク | 回答の録音のファイル名と、ドライブで開くリンク。 |
| 録音2／録音2リンク | 提案例文の録音（ある場合）。 |
| 録音なしの理由 | 参加者が「マイクが使えない」を選んで回答した場合に入ります。 |
| 録音の長さ（秒）／サンプリング周波数 | 録音1のもの。 |
| 回答にかかった秒数 | 設問が表示されてから「つぎへ」を押すまで。 |
| 端末 | おおまかな機種とブラウザ。 |
| 端末での回答日時 | 参加者の端末の時計での日時。日本時間で、`2026-10-12T08:41:03+09:00` の形で入ります（通信できなかった回答は、送信日時より前になります）。 |
| 送信ID | 二重登録を防ぐための番号。 |
| 技術情報 | 録音についての細かい情報（下の「録音」を見てください）。 |
| 声と雑音の差（dB） | 録音1について、声の大きさと、まわりの音の大きさの差を見積もった数字（SN比の見積もり）。大きいほど、静かな場所で録れています（下の「まわりの音（雑音）」を見てください）。 |

回答の文字は、参加者が書いたとおりに保存されます（全角・半角をそろえたり、「か゜」のような書き方を別の文字に置きかえたりはしません）。
`=`・`+`・`-`・`@` で始まる回答も、表計算の数式として動かないように、文字として保存します（そのセルを選ぶと、先頭に `'` が見えることがあります）。

### 録音

- 形式：WAV（無圧縮・16ビット・モノラル）。サンプリング周波数は端末まかせ（多くは 44,100 Hz か 48,000 Hz）。
- 端末の自動補正（エコー除去・雑音除去・音量の自動調整）は、切るように求めています。端末によっては切れないことがあります。
- 保存場所：録音フォルダ → 参加者ナンバーのフォルダ。
- ファイル名：`参加者ナンバー_設問ID_kaitou_日付-時刻_送信IDの先頭.wav`（提案例文は `kaitou` のかわりに `reibun`）。
- 音がまったく入っていない録音、とちゅうで切れた録音は、参加者の画面で受けつけず、録り直してもらいます。ほとんど何も録れていないほど音が小さい録音、大きすぎる録音は、受けつけたうえで、録り直しをすすめます。
- 録音の音量は、端末によって大きくちがいます。iPhone・iPad は、音量の自動調整が切れるので、ふつうの声でも `peak` が 0.03 くらい（録音できる最大の 3%）と小さく録れます。声と雑音の差が十分あれば、品質に問題はありません。聞くときや分析するときに、ソフトで音量を上げて使ってください。
- そのため、参加者への注意は、音量そのものではなく、「声と雑音の差」で出します（下の「まわりの音（雑音）」）。
- 参加者が「聞く」を押したときは、聞きとりやすいように、音を大きくして流します。保存される録音は、もとの音量のままです。

「技術情報」の列には、録音ごとに次の情報が入ります（`main` が回答の録音、`ex` が提案例文の録音）。

| 名前 | 内容 |
| --- | --- |
| `sec`／`hz` | 録音の長さ（秒）と、WAV のサンプリング周波数。 |
| `peak` | 最大の音量（0〜1）。0.005 より小さいと「とても小さい」、0.985 以上だと「割れているかもしれない」あつかいです。 |
| `snr`／`noise` | 声と雑音の差（dB）と、まわりの音の大きさ（dB。0 がいちばん大きい音で、マイナスの数字が大きいほど静か）。提案例文の録音（`ex`）の値は、ここにだけ入ります。 |
| `ec`／`ns`／`agc` | エコー除去・雑音除去・音量の自動調整。`true` なら、切れていません。 |
| `trackHz` | マイクそのもののサンプリング周波数が、WAV とちがうときだけ入ります。 |
| `input` | `bluetooth` と入っていたら、無線のイヤホンなどのマイクで録音されたようです（音の帯域がせまくなります）。 |

### まわりの音（雑音）

- 録音ごとに、声の大きさと、話していないあいだの音（まわりの音）の大きさの差を、参加者の端末で見積もります。
- この差が、「設定」シートの「雑音の注意の目安（dB）」より小さいと、参加者の画面に「まわりの音が大きいようです。静かな場所で、口を近づけて、録り直してみてください。」と出ます。注意が出ても、そのまま進めます。
- 「録音のれんしゅう」でも同じように確かめ、まわりの音が大きいときは、問題に入る前に知らせます。
- 見積もった数字は、「回答」シートの「声と雑音の差（dB）」に残ります。この列で並べかえると、雑音の多い録音を拾えます。
- 数字のおおよその目安は、静かな部屋で 35 以上、換気扇や車の音がはっきり聞こえる場所で 20 以下です。ただし、この目安は計算の上でのもので、機種によって数字の出方がちがいます。試行調査で集まった数字と、実際の録音の聞こえ方を見くらべて、「雑音の注意の目安（dB）」を調整してください。
- 拾えるのは、換気扇・エアコン・車のように、鳴りつづけている音です。近くで別の人が話している声、テレビの話し声、とつぜんの物音は、本人の声と区別できないので、数字に表れないことがあります。
- 端末が雑音を自動で消している場合（「技術情報」の `ns` が `true`）は、実際よりも静かに見えます。
- 声の入っていない録音や、ごく短い録音では、空欄になることがあります。端末が、話していないあいだの音をまったくの無音にしてしまう場合も、見積もれないので空欄になります。

### 進み具合

参加者ごとの進み具合は、管理画面の「ダッシュボード」と「参加者」で、いつでも見られます。
表の形で手もとに残したいときは、メニュー「方言調査」→「進み具合を更新」で、参加者ごとの回答数をまとめた「進み具合」シートを作れます。

## 参加者の画面について

- 回答は、まず参加者の端末の中に保存され、通信できるときに自動で送られます。画面の右上が「送信ずみ」になっていれば、すべて届いています。
- 歩を終えたときの画面には、送信の状態が大きく出ます。「回答はすべて送信されました」と出るまで、ページを閉じないように案内してください。
- 通信できないままブラウザのデータを消すと、まだ送られていない回答は失われます。
- 端末の保存場所がいっぱいなどの理由で、端末の中に回答を保存できないことがあります。そのときは、1問ごとに、保存先に届いてから次の問題へ進みます（画面にその知らせが出ます）。
- 録音は原則として必須です。参加者が「マイクが使えないとき」→「録音なしで進む」を選んだ場合だけ、文字の回答だけで進めます。この選択は、その歩のあいだだけ有効で、次の歩では、もう一度録音をためしてもらいます。
- 回答を書いているとちゅうで、ブラウザの「戻る」を押したり、ページを閉じようとしたりすると、確認が出ます。
- ボタンを続けて2回押してしまっても、2回目は受けつけません（画面が切りかわってから約0.4秒のあいだ）。

## 知っておくとよい上限

- 1回の保存には数秒かかり、同時に処理できる数にも Google 側の上限があります。試行調査の規模では問題になりませんが、保存先がこみあった場合、回答は参加者の端末に残り、あとで自動的に送り直されます。
- 回答が数万行を超えると、ログイン直後の読みこみが遅くなります。数百人規模で使う前に、作りを見直してください。
- iPhone（Safari）は、7日以上開かなかったサイトについて、端末の中のデータを消すことがあります。その場合、ログインはやり直しになり、まだ送られていなかった回答は失われます（保存先に届いた回答と進み具合は残ります）。「送信ずみ」を確かめてから閉じるよう、案内してください。
- 録音は1本あたり、20秒でおよそ2MBです。Google ドライブの空き容量を、ときどき確かめてください。
